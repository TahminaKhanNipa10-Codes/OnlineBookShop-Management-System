## 📖 Project Overview
This is a **Professional Database Project** developed during my intensive Software Development training at **IsDB-BISEW**. This system serves as a robust backend for an Online Bookstore, focusing on data integrity, complex relationships, and optimized query performance.

## 🛠️ Key Technical Features
- **Relational Architecture:** Designed with 16+ normalized tables to ensure zero data redundancy.
- **Inventory & Variants:** Advanced tracking of book formats, pricing, and real-time stock levels.
- **Order Management:** End-to-end workflow from order placement to shipping and payment confirmation.
- **Business Logic:** Implementation of discounts, user reviews, and complaint handling systems.
- **Database Objects:** Includes optimized DDL/DML scripts for seamless setup and testing.
